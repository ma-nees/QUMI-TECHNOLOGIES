# 13 — Animation Guidelines
Durations 180–500ms, ease `cubic-bezier(.2,.7,.2,1)`. Hero staggered fade-up on load; sections fade-up once on scroll (`Reveal`); process timeline line fills on scroll. Hover: translateY(-2px), border darken, arrow +4px, image scale 1.04. All disabled under `prefers-reduced-motion`.
