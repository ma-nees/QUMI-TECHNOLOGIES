# 12 — UI/UX Design System
Palette (brand): Cobalt #0047AB (primary), Cream Linen #FAF3E7 (warm surface), White (cards/nav), Deep Navy #0B1F3A (text), Slate #667085 (muted), Warm Gray #E6E0D7 (borders), Tangerine #F28C28 (sparing accent). All defined as oklch tokens in `src/styles.css`.
Type: Manrope 400–800; JetBrains Mono uppercase eyebrows. Radius 6px base; cards mostly square-cornered with 1px borders. 12-column container max 1240px. Buttons rectangular, moderate radius, arrow nudge on hover.
